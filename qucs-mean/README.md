# Qucs Mean Calculator (Qt6)

This is a simple Qt6 GUI application to calculate the arithmetic mean of two numbers.

It is intended to be integrated into the main Qucs-S application environment.

## Building

Use CMake or qmake with a Qt6 environment.

### CMake
```bash
mkdir build
cd build
cmake ..
make
```

### qmake
```bash
qmake qucsmean.pro
make
```
